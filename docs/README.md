# Documentation

Documentation tracks the current version declared in the root `package.json`. Installed package contracts remain the version-specific authority:

- `README.md` covers installation, package consumption, AI setup, and releases.
- `COMPONENTS.md` lists the current component catalog and broader roadmap vocabulary.
- `DESIGN.md` defines system-wide ownership and styling architecture.
- `docs/foundations.md` documents the current typography, spacing, elevation, and target-size foundations.
- `docs/ai-composition.md` documents version-aware product composition and verification.
- `src/components/<name>/README.md` provides colocated guidance for public atomic components.
- `contracts/design-system.contract.json` and each colocated `*.contract.json` remain authoritative when prose drifts.
